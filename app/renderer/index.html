Configuración

        
      

      

        
        

          
Apariencia

          
Elegí cómo se ve y cómo se llama. El color también se aplica en la página del celular.

          
          
          
Va a usar este nombre para presentarse y responder, también por voz.

          

        

        

          
Perfil

          
Cómo te ve Mentis. Esto se le manda en cada turno para que te conozca, no hace falta repetirlo en el chat.

          

            
            

              
              
              
              
            

          

          
          
          
        

        

          
Memoria sobre vos

          
Base de lo que Mentis sabe de vos. La arrancás vos; Mentis la va a ir actualizando sola cuando aprenda algo nuevo y duradero.

          
          

          
        

        

          
Memoria sobre Mentis

          
Autoconocimiento de Mentis: quién es, qué es, qué se le da bien o mal -- no hechos sobre vos (esos van arriba). Vos la podés escribir/corregir acá, y Mentis la va a ir completando sola.

          
          

          
        

        

          
Modelos personalizados por rol

          
Cada cerebro (código, razonamiento, etc.) puede apuntar a tu propia API en vez del ensemble NIM de fábrica. Los proveedores "OpenAI-compatible" (OpenAI, Groq, OpenRouter, Ollama/LM Studio local, etc.) funcionan ya mismo. Anthropic y Gemini con su formato propio quedan guardados pero todavía no están conectados.

          

        

        

          
Ideogram (imágenes con texto/logos)

          
Para logos, carteles o cualquier imagen donde el texto tenga que leerse bien -- Mentis usa esto en vez del generador general cuando corresponde. Necesita tu propia API key de ideogram.ai.

          

          

            
            
          

        

        

          
Video (Runway)

          
Genera videos reales a partir de texto (Runway anima un frame inicial con tu descripción -- la API pública de Runway no tiene texto→video puro, siempre necesita una imagen de base, que Mentis genera sola). Necesita tu propia API key de dev.runwayml.com.

          

          

            
            
          

        

        

          
Backup

          
Exporta un.zip con todo lo que no se puede regenerar: conversaciones, proyectos, tu memoria/perfil, y tus skills. No incluye tus API keys ni las imágenes/videos/documentos ya generados (esos quedan en tu carpeta Documents/Mentis de todos modos).

          
          

        

        

          
Tema visual

          
"Bitácora de campo" es el único tema por ahora.
